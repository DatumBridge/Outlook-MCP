# Workflows — Outlook MCP

1. Operator registers Azure app Weaver Integration Outlook with Graph delegated Mail scopes.
2. Operator sets `OUTLOOK_CLIENT_ID` / `OUTLOOK_CLIENT_SECRET` on Integrations.
3. User Connects Outlook in Studio.
4. Operator publishes Outlook MCP and grants tools on the Digital Employee.
5. Deep calls list/get/send/draft tools with injected credentials.
