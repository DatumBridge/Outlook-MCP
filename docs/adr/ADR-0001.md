# ADR-0001 — Separate Outlook Azure app

## Context

office365-mcp covers OneDrive, SharePoint, and Teams. Combining Mail.* into that Azure app would force every files user to consent to mailbox access.

## Decision

Ship `outlook-mcp` with vault provider `outlook` and `OUTLOOK_CLIENT_ID` / `OUTLOOK_CLIENT_SECRET`. Do not add Mail scopes to the Microsoft 365 files app.

## Alternatives Considered

- One Azure app, extra scopes on office365-mcp — rejected (consent blast radius).
- Share Google-style one OAuth client for two MCP servers — rejected by operator (Microsoft analog of Gmail vs Drive sharing one client).

## Consequences

Users Connect Outlook and Microsoft 365 separately.

## Trade-offs

Two Azure apps and two Connect cards to operate.

## Risks

Vault matcher must not inject office365 tokens into outlook-mcp-main.
