# Integrations — Outlook MCP

Vault provider: `outlook`.

OAuth start/callback:

- `/api/v1/credentials/oauth/outlook/start`
- `/api/v1/credentials/oauth/outlook/callback`

Env on Integrations: `OUTLOOK_CLIENT_ID`, `OUTLOOK_CLIENT_SECRET`, optional `CREDENTIAL_OAUTH_REDIRECT_URI_OUTLOOK`, optional `OUTLOOK_TENANT_ID`.
